# 🛒 Smart Cart

Smart Cart is a mini-project designed to provide a simple and efficient shopping experience by managing products, cart items, and purchase details.

## 📌 About the Project

Smart Cart is a project that demonstrates the basic implementation of an online shopping cart system. Users can view available products, add products to their cart, manage quantities, and calculate the total cost of their selected items.

The project was developed as a learning project to understand the practical implementation of programming concepts and build a functional shopping-based application.

## ✨ Features

- 🛍️ View available products
- ➕ Add products to the cart
- ➖ Remove products from the cart
- 🔢 Manage product quantities
- 💰 Calculate total cart amount
- 📋 Display selected products and their details
- 🧮 Automatic total price calculation
- 🖥️ Simple and user-friendly interface

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/smart-cart.git
```

2. Open the project folder:

```bash
cd smart-cart
```

3. Start JupyterLab:

```bash
jupyter lab
```

4. Open `Smart_Cart.ipynb`.

5. Run the notebook cells in order.
